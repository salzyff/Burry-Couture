# Burry Couture website mockup

A responsive React and Vite concept for Burry Couture, designed around the brand's bridal, bespoke, aso ebi, custom-made and promwear services.

## Run locally

```sh
npm install
npm run dev
```

The booking, Instagram, email, and WhatsApp links point to Burry Couture's public contact channels. The editorial bridal images are from a BellaNaija Weddings feature that credits Burry Couture; confirm usage permission and replace with approved brand-owned photos before publishing publicly.
